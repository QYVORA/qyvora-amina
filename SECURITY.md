# Security Policy

## Supported Versions

Only the latest tagged release receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability in AMINA, please report it privately by emailing the QYVORA OffSec team at **qyvorasec@gmail.com**. **Do not open a public GitHub issue.**

We will acknowledge receipt within 48 hours and provide an estimated timeline for a fix. Once the fix is released, we will credit the reporter (if desired) in the release notes.

## Contact

- **Website:** https://qyvora.org
- **Security contact:** qyvorasec@gmail.com
- **Organisation:** QYVORA OffSec — Tamale, Ghana

## Scope

This policy covers the AMINA source code, build pipeline, and release artifacts. Issues related to the local host being assessed are out of scope — those should be reported to the host owner.

Amina performs read-only local-host assessment. It never modifies the host.

## Responsible Disclosure

We ask that you give us reasonable time to patch and release a fix before any public disclosure.
